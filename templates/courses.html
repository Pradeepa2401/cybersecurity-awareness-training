📚 Learning Material

{% if title == "Password Security" %}
  • Use long and unique passwords.
  • Do not reuse the same password for important accounts.
  • Never share your passwords with other people.
  • Use multi-factor authentication when available.
{% elif title == "Phishing Awareness" %}
  • Phishing messages often try to create urgency.
  • Check the sender before responding.
  • Be careful with unexpected links and attachments.
  • Verify unusual requests through a trusted channel.
{% elif title == "Safe Internet Practices" %}
  • Keep your browser and software updated.
  • Download applications from trusted sources.
  • Check website addresses before entering information.
  • Be careful when using public Wi-Fi.
{% elif title == "Social Media Safety" %}
  • Review your privacy settings regularly.
  • Avoid publicly sharing sensitive personal information.
  • Be careful when accepting requests from unfamiliar accounts.
  • Use strong security settings for your accounts.
{% elif title == "Social Engineering Awareness" %}
  • Social engineering uses manipulation to influence people.
  • Be cautious of unexpected requests for confidential information.
  • Urgent requests should be independently verified.
  • Pause and think before responding to unusual requests.
{% elif title == "Mobile & Device Security" %}
  • Keep your device software updated.
  • Use a screen lock.
  • Install applications from trusted sources.
  • Review application permissions.
  • Keep backups of important information.
{% endif %}
